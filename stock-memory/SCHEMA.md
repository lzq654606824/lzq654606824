# 记忆字段定义

每条记忆是一个 Markdown 文件：开头 `---` 之间是字段（frontmatter），后面是正文。
`tools/memory.py check` 按本文规则校验；要增删取值（例如新的来源类别），同时改本文和 `tools/memory.py` 顶部的常量。

## 三类记忆

| type | 中文 | 存放目录 | id 前缀 | 用途 |
| --- | --- | --- | --- | --- |
| `note` | 行情笔记 | `notes/` | `N` | 当天看到的盘面、消息和自己的理解 |
| `review` | 交易复盘 | `reviews/` | `R` | 一笔交易从理由到结果的回顾和教训 |
| `lead` | 市场线索 | `leads/` | `L` | 暂时没下结论、值得之后回头验证的信号 |

## 公共字段（三类都有）

| 字段 | 必填 | 格式 | 说明 |
| --- | --- | --- | --- |
| `id` | 是 | `<前缀>-YYYYMMDD-HHMM`，同一分钟重复时加 `-2`、`-3` | 写入时刻（上海时间）生成，之后不再改，用于互相引用 |
| `type` | 是 | `note` / `review` / `lead` | 必须和所在目录一致 |
| `title` | 是 | 一句话 | 列表里显示的标题 |
| `date` | 是 | `YYYY-MM-DD` | 这条记忆对应的市场日期（上海时间）。按时间找回用的就是它 |
| `created` | 是 | `YYYY-MM-DDTHH:MM:SS+08:00` | 实际写下的时间；补记时 `date` 和 `created` 会不同 |
| `symbols` | 是（可为空） | `[600519.SH, 00700.HK]` | 标的代码，写成 `代码.市场` 大写：`SH` 上交所、`SZ` 深交所、`BJ` 北交所、`HK` 港股、`US` 美股。不针对具体标的就写 `[]` |
| `tags` | 是（可为空） | `[白酒, 量价/放量]` | 自由标签，可用 `/` 分层；不带 `#`、空格和逗号 |
| `source` | 是 | 见下表 | 信息来源类别 |
| `source_ref` | 否 | 文本 | 出处：链接、公告标题、书名页码或一句说明 |
| `related` | 否 | `[L-20261020-0930]` | 相关记忆的 id，例如复盘指向触发它的线索 |

`source` 取值：

| 值 | 含义 |
| --- | --- |
| `self` | 自己的观察或操作 |
| `announcement` | 公司或交易所公告 |
| `news` | 新闻媒体 |
| `research` | 研究报告 |
| `data` | 统计数据、宏观数据 |
| `social` | 社交媒体、论坛 |
| `people` | 他人转述 |
| `other` | 其他（在 `source_ref` 里说明） |

## 交易复盘（review）额外字段

| 字段 | 必填 | 格式 | 说明 |
| --- | --- | --- | --- |
| `direction` | 是 | `long` / `short` | 做多 / 做空 |
| `opened` | 是 | `YYYY-MM-DD` | 开仓日期 |
| `closed` | 平仓后必填 | `YYYY-MM-DD` | 平仓日期，不能早于 `opened` |
| `result` | 是 | `open` / `win` / `loss` / `flat` | 未平仓 / 盈 / 亏 / 持平 |
| `pnl_pct` | 否 | 数字，如 `-3.5` | 收益率（%），不带 `%` |

复盘的 `date` 填平仓日；还没平仓就填复盘当天。框架不设金额、持仓数量、账户等字段。

## 市场线索（lead）额外字段

| 字段 | 必填 | 格式 | 说明 |
| --- | --- | --- | --- |
| `status` | 是 | `open` / `confirmed` / `invalidated` / `expired` | 待验证 / 已应验 / 已落空 / 过期不再跟踪 |
| `review_on` | 否 | `YYYY-MM-DD` | 计划回头复查的日期；`find --due` 会列出到期的 |

## 文件命名

`<目录>/<date 的年份>/<date>-<短标题>.md`，例如 `notes/2026/2026-11-06-尾盘放量.md`。
同名时加 `-2`。文件名只为方便浏览，查找以字段为准。

## frontmatter 写法限制

工具只解析以下写法（都是合法 YAML，Obsidian 等工具也能读）：

- `键: 值`；值里有 `: `、或以 `[`、`#`、引号开头时，用双引号包起来
- 列表写成 `[a, b]`，或 `键:` 换行后每行 `  - a`
- 整行 `#` 开头是注释

不支持嵌套字段和多行文本；长内容写在正文里。
